# ピピトリ オンライン v46

3〜5人で遊ぶ、トリックテイキング × ババ抜きのオンラインカードゲームです。既存ルールと機能を維持し、人数追加後の不整合を修正しています。

## 起動・Renderへの反映

Node.js 22を使用します。このフォルダーをプロジェクトのルートとして配置してください。

```sh
npm ci
npm start
```

ローカルでは http://localhost:3000 で開きます。RenderではBuild Commandを `npm ci`、Start Commandを `npm start` とし、サービスから渡される `PORT` を使用します。ZIPの反映は手動です。公開中のSitesは既存RenderのWebSocketへ接続する構成を維持します。

部屋と対戦状態はサーバーのメモリー内にあり、再起動・再デプロイで失われます。対戦が終わってから反映してください。

## 遊び方

名前と参加方法を選び、部屋を作るか4文字のコードで参加します。ホストはCPUを選んで追加し、指定人数がそろったら開始できます。CPUは「かももどき」「ワクもどき」「リクもどき」「なかとーもどき」から選択できます。観戦・再接続・離脱・再戦にも対応しています。

## 現行の標準ルール

|人数|手札|基本ピック|中位の追加ピック|
|---|---|---|---|
|3人|17枚ずつ|1位→3位|対象外|
|4人|13枚ずつ|1位→4位|2位→3位|
|5人|10枚ずつ|1位→5位|2位→4位|

- 3ラウンド。ラウンド間は全カードを回収してシャッフルします。
- ごちそう山は1枚+1点。通常の残り手札は1枚-3点、ぬかるみは-6点。
- マッド・ピッグ（ぬかるみの11）は固有-13点。通常カードの失点とは重複しません。
- ババブタは-20点、各ラウンドで適用。
- ピック候補は2枚。ババブタを持つ提供者は、必ず候補に含めます。
- 中位の追加ピックはON。3人用では実施しません。
- シュート・ザ・ピッグ、装填→発射、3枚パス、開始時ペア捨てはOFF。
- 詳細設定で変更できます。対戦中のルール早見表で適用中の設定を確認できます。
